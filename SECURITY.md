# Security

- This repository contains **no** credentials, instance URLs, client data or employer code.
- All sample data is synthetic. IP addresses use the RFC 5737 documentation ranges.
- Configuration is supplied through `config.example.json`; copy it to `config.json` (git-ignored) for local values.
- In a ServiceNow instance, store endpoints and secrets in Connection & Credential Aliases or system properties — never in script bodies.

To report a problem, open an issue without including any sensitive data.
